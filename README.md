# XIV Data Snapshots

Versioned Final Fantasy XIV game data snapshots (.xivsnap) hosted via GitHub Releases for [XIV Data Viewer](https://github.com/InfSein/xiv-data-viewer).

- catalog.json: Master index mapping player patch names (e.g. 7.58) to client build versions (e.g. 2026.11.03.0000.0000) and release download assets.
- Releases: Self-contained .xivsnap archives containing EXD tables, matching EXDSchema definitions, and lightweight BGM/icon manifests.
